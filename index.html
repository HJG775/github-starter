打开命令速查 我要上线

五个动作，覆盖 90% 的日常

不用背命令，先记住这个顺序。

  1. 01

    改文件

    在工作区里编辑代码，此时 Git 只是“看到”了变化，还没有记录。

    git status
  2. 02

    挑出这次要提交的内容

    把改动放进暂存区，相当于给这次提交圈定范围。

    git add .
  3. 03

    拍一张快照

    提交后，这个状态就被永久记进本地历史，随时可以回到这里。

    git commit -m "说明"
  4. 04

    同步到云端

    推到 GitHub，别人能看到，你的硬盘坏了也不会丢。

    git push
  5. 05

    合进主干

    在网页上开一个 Pull Request，评审通过后合并到 main。

    Pull Request

命令速查

点任意一行复制。忘了就搜，不用背。

    没有匹配的命令，换个关键词试试。

    把它发布成网址

    仓库里已经配好了自动部署，你只需要推上去。

    1

    在 GitHub 建一个空仓库

    不要勾选自动生成 README，否则推送时会冲突。

    2

    连上远端并推送

    git remote add origin git@github.com:用户名/仓库名.git
    git push -u origin main

    3

    打开 Pages

    仓库 Settings → Pages → Source 选 GitHub Actions。之后每次 push 到 main 都会自动重新部署。

    大约一分钟后，访问 https://用户名.github.io/仓库名/ 就能看到这一页。
